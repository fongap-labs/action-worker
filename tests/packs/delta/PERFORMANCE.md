# Delta 精选性能冒烟

本测试由 Action Worker 的可信 CI 负责，不恢复上游多千份 Snapshots 或完整 benchmarks 目录。仅运行短时合成数据场景，不访问用户会话、凭据、浏览器或网络。

已纳入的场景：

1. 8 MiB 工具输出进入真实 TextRetainer，验证上下文输出最多保留 128 KiB。
2. 12,000 条合成会话列表元数据进入真实 ItemRetainer，验证有限保留和线性输入通路。
3. 独立 Node 进程冷导入真实 Delta Code Host 插件，记录模块导入耗时。
4. 本地诊断模块存在时，记录 1,200 次故障并验证日志轮转、容量和无原始错误消息。

每个场景记录实际 wall-time 和必要的内存指标。**当前不设置伪造的毫秒门限**；先取得可比较的 Linux Runner 样本，再依据真实机器基线、噪声和容量配置审定回归阈值。

尚未覆盖完整 Agent 多轮工具流水线、Session 真实磁盘加载、模型摘要式上下文压缩或 GUI 渲染性能。这些需要专门的稳定工作负载和中央执行预算，不能把上述合成案例误称为完整性能验收。
